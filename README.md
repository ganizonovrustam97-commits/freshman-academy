# Freshman Academy — SAT & AP Prep

Одностраничный сайт академии: программы SAT и AP, сопровождение поступления,
конструктор индивидуального пакета с генерацией коммерческого предложения.

## Структура
- `index.html` — весь сайт (HTML + CSS + JS в одном файле)
- `media/results/` — результаты поступлений студентов
- `media/video/` — видео и постеры к ним
- `media/mentors/` — фотографии менторов сопровождения
- `logo.png` — логотип

## Как редактировать
Правки вносятся в `index.html`. После коммита в ветку `main`
GitHub Pages пересобирает сайт автоматически за 1–2 минуты.

Цены на программы Admissions / Essay / Applications заданы
в объекте `PRICES` внутри `<script>` — там же комментарии.
